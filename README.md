# BeOriginalX — Portal 0.1

**Create. Innovate. Execute.** Portal experimental de projetos digitais, independente da aplicação Versátil.

## Acesso e publicação

Site estático de um só ficheiro (`index.html`), sem serviços externos obrigatórios, sem bases de dados e sem cookies de rastreio introduzidos pelo projeto. Compatível com browsers móveis, incluindo Samsung Galaxy.

Para ativar o alojamento gratuito do GitHub Pages neste repositório público:
1. Abrir **Settings → Pages**.
2. Em **Build and deployment**, selecionar **Deploy from a branch**.
3. Selecionar **main** e **/(root)** e carregar em **Save**.
4. Confirmar o endereço publicado em **Settings → Pages**.

O endereço provisório continua no alojamento GitHub Pages. A identificação da conta e o nome do alojamento só desaparecem do URL público quando existir um domínio alternativo efetivamente configurado.

## Funcionalidades

- Página inicial com identidade BeOriginalX
- Catálogo de seis áreas de projeto
- Pesquisa e filtros por categoria
- Janelas informativas e navegação acessível
- Suporte a dispositivos móveis e preferências de movimento reduzido

## O que ainda não existe

Este portal público **não fornece** armazenamento privado, upload de ficheiros, autenticação, VPN, subdomínios próprios ou domínio personalizado. Estes serviços necessitam de infraestrutura e configuração adicionais. Não colocar neste repositório tokens, senhas, chaves, perfis VPN, documentos privados ou dados de terceiros.

O uso de GitHub Pages gratuito está sujeito à continuidade da disponibilidade e às condições de serviço do GitHub. Não é uma garantia vitalícia nem de independência de terceiros.

## Domínio personalizado pretendido

**beoriginalexe.eu.org** — escolhido, mas **ainda não registado nem aprovado** no EU.org. O serviço EU.org exige nameservers DNS previamente configurados e validação manual da candidatura. Manter o endereço GitHub Pages operacional até haver confirmação; só então configurar a zona DNS e o domínio personalizado no GitHub Pages. Não adicionar um ficheiro `CNAME` antes da confirmação do domínio e do plano DNS.
